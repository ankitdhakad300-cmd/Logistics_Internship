
# Week 1: Logistics Strategic Planning

## Project Overview
This project analyzes sample logistics delivery data using Python.
The goal is to understand delivery performance and identify delayed orders.

## Tools Used
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Dataset
The project uses sample data for six orders, including:
- Order ID
- Delivery distance
- Expected delivery time
- Actual delivery time

This is practice data created for learning purposes.

## Analysis Performed
- Displayed the delivery dataset
- Calculated delivery delays
- Identified delayed orders
- Calculated average actual delivery time
- Found the order with the highest delay
- Created a bar chart of actual delivery times

## Key Findings
- Average actual delivery time was approximately 4.33 hours.
- Orders 102, 104, and 105 were delayed.
- Order 104 had the highest delay of 2 hours.

## Conclusion
This project demonstrates how Python can help analyze logistics
performance and identify delivery delays. Such analysis can support
better planning and operational decisions.
